# Kaza Defteri: Arayüz Metinleri

Kurallar: sade Türkçe, "sen" hitabı, saygılı ve sakin ton. Uygulama hüküm bildirmez, öğüt vermez, suçlamaz. `{süslü}` alanlar değişkendir. Vakit adları: Sabah, Öğle, İkindi, Akşam, Yatsı, Vitir.
